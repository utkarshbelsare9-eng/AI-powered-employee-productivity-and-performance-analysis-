Privacy-first activity collection

This optional desktop agent measures activity for productivity analysis without capturing the content of your work.

  • Keyboard: press count only — no key names and no typed text.
  • Mouse: movement, clicks and scroll counts.
  • Idle time: seconds without keyboard/mouse input during each interval.
  • Application: process/app name only; no window/document title.
  • Data is sent as one aggregate record every 60 seconds.
Use this only with appropriate employee notice/consent and your organization's applicable privacy and workplace policies.
